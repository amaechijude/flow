`scripts/validate-ebpf-attribution.py`; see `docs/attribution.md` for gates and
caveats.

Reports before the TCP+UDP/per-interface change were produced by a TCP-only
harness and contain no protocol/interface checks. New reports run TCP and UDP
transfers and include per-protocol totals plus expected-interface (`lo`)
attribution.
